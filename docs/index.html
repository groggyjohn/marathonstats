Outline

This project presents various views of mass participation finishing times from runners of the London Marathon.

This page has interactive plots, and the interactions works best with a computer which has a mouse or trackpad. The plots work on mobile devices, but some things work differently (eg pinch-to-zoom is not supported - zoom needs to be done through '+' and '-' icons found on plots, where available)

Marathon comments:

  • 2018: Hottest London marathon recorded so far (24.2°C)
  • 2020: No London mass participation event due to covid. Results are from the virtual marathon where registered runners completed their own route and uploaded their time via the official app.
